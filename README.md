# 액션 자리뽑기

학생들이 텍스트 RPG처럼 17단계 모험으로 캐릭터를 키우고, 결승전(**3D 육상 레이스** 또는 **3D 아레나 배틀로얄**) 등수대로 자리가 정해지는 자리 배치 웹앱입니다.
교사의 비밀 조건(떨어뜨리기·짝 만들기·자리 고정·앞/뒷자리)은 결과에 몰래 반영됩니다.

## 화면 구성
| 화면 | 파일 | 누가 보나 |
|---|---|---|
| 교사 콘솔 (메인) | `public/index.html` | 선생님만 (교실 배치·명단·비밀 조건·진행 버튼·초기화) |
| 학생 화면 | `public/play.html` | 학생 휴대폰 (참여 코드 → 이름 → 게임 설명 → 직업 → 모험 17단계 → 결과) |
| 발표 화면 | `public/stage.html` | 프로젝터 (대기실·진행판·결승전·자리 발표). **메뉴/비밀 정보가 없음** |

- 방을 만들면 발표 화면이 **새 창**으로 열립니다. 프로젝터 쪽으로 옮기고 전체 화면(F11 또는 마우스를 움직이면 나오는 버튼)을 켜세요. 팝업이 차단되면 허용한 뒤 '발표 창 열기'를 누르세요.
- 모니터가 1대면 '이 창에서 발표'를 눌러 콘솔 위에 발표 화면을 덮을 수 있습니다. 아래쪽에 마우스를 가져가면 진행 버튼(도크)이 나타납니다.
- 발표 화면은 한 번에 하나만 켜지고, 교사 콘솔도 한 탭에서만 동작합니다(두 개가 동시에 돌면 결승전이 두 번 실행됨).
- 학생 화면은 태블릿 가로에서 스크롤 없이 한 화면에 나옵니다. 배치는 `public/css/student.css`에서 고칩니다.
- 콘솔과 발표 화면은 같은 브라우저 안에서 BroadcastChannel로 통신하며, 비밀 조건은 발표 화면으로 전달되지 않습니다.

## 학생 모험 (17단계)
- 갈림길 3번에서 길을 고르면 그 길의 이벤트 3개가 무작위로 나와서 학생마다 모험이 달라집니다.
  - 숲속 오솔길: 이야기 선택, 마음의 질문
  - 험난한 지름길: 함정, 괴물, 바위 깨기, 황금 슬라임 (위험하지만 보상이 큼)
  - 고대 유적: 수수께끼, 10 만들기, 초성 퀴즈, 창의력(새로운 쓰임새), 짝 맞추기, 슬라이드 퍼즐
  - 떠돌이 시장: 상점, 주사위 도박, 점술, 미믹 상자
- 일부 선택지는 주사위 판정(1~20 + 능력치/3)이라 실패하면 능력치가 깎이기도 합니다.
- 골드를 모아 상점에서 쓰고, 남은 골드는 마지막에 행운으로 바뀝니다.

## 짝 방향
교실 배치 탭 > '짝 방향'에서 **좌우가 짝**(책상이 칠판과 나란히) 또는 **앞뒤가 짝**(모둠형, 책상이 칠판과 수직)을 고릅니다.
짝 만들기·떨어뜨리기(옆자리 범위)·지난번 짝 피하기·짝꿍 고르기 보상이 모두 이 기준을 따릅니다. '4인 모둠' 빠른 배치는 앞뒤가 기본입니다.

## 1·2·3등 보상: 짝꿍 고르기
- 결승전이 끝나면 1·2·3등 휴대폰에 무작위 후보가 번호판처럼 공개됩니다. 1등은 5명, 2등은 4명, 3등은 3명 중에서 한 명을 골라요.
- 후보에는 비밀 조건(떨어뜨리기·짝 만들기·자리 고정·앞/뒷자리)이 걸린 학생과 지난번 짝이 몰래 빠지고, 세 명의 후보는 서로 겹치지 않습니다.
- 접속한 학생만으로 후보가 모자라면, '결석한 학생도 자리 배정' 옵션을 켰을 때 결석한 명단 학생으로 채웁니다(학생 1명으로 시험할 때도 이 옵션을 켜세요). 건너뛴 경우 이유는 교사 콘솔에만 표시됩니다.
- 다 고르면(또는 교사가 '짝 고르기 마감'을 누르면) 1~3등은 등수대로 자리를 받고, 고른 짝은 그 바로 옆자리에 앉도록 다시 계산한 뒤 결과를 발표합니다.
- 발표 화면에는 누가 후보였는지, 누구를 골랐는지 나오지 않습니다. 끄려면 비밀 조건 탭 > 옵션에서 해제하세요.

## 그래픽·소리
- 캐릭터: KayKit Adventurers·Skeletons (Kay Lousberg, CC0). 색·모자·악기 등을 바꿔 6직업으로 조립합니다. `public/assets/models/LICENSE.txt`
- 효과(불·마법진·충격파 등)와 경기장은 코드로 그립니다. 효과음·배경음악도 `tools/make-sfx.js`, `tools/make-music.js`로 직접 합성했습니다(외부 음원 없음). 다시 만들기: `tools\build-audio.ps1`
- 배경음악은 발표 화면에서만 납니다. 교사 콘솔의 '음악 끄기', '소리 끄기'로 조절하고, 학생 화면은 오른쪽 위 스피커 버튼으로 끕니다.
- 결승전 화면 품질은 컴퓨터 속도에 맞춰 3단계로 자동 조절되고 기억됩니다(브라우저 저장소 `action-seat-gfx`: 2 높음, 1 보통, 0 낮음. 지우면 다시 측정).

```
public/js/gamedata.js   직업 6종, 능력치, 모험 이벤트·갈림길·수수께끼 (내용 수정은 여기서)
public/js/sfx.js        효과음 재생
public/js/solver.js     자리 배정 알고리즘 (조건 만족 + 능력치 순위와 최대한 비슷하게)
public/js/gfx/race.js    3D 육상 레이스 (three.js 0.170)
public/js/gfx/battle.js  3D 배틀로얄·필살기 6종
public/js/gfx/chars.js   캐릭터 조립(직업별 색·장비는 LOOKS)
public/js/gfx/core.js    3D 무대·품질 조절·관중   fx.js 파티클 등 효과 도구
public/js/fxkit.js      결승전 공통 HUD (컷인, 배너, 해설, 순위표, 꽃가루)
public/js/config.js     Supabase 연결 정보
public/css/student.css  학생 화면 배치 (태블릿 가로)
public/assets/          models(3D) chars(캐릭터 그림) sfx(소리) icons·scenes(Gemini로 생성한 이미지)
tools/build-models.js   KayKit 원본을 작게 만드는 스크립트
tools/gen-assets.ps1    에셋 시트 생성 스크립트 (원본은 tools/raw)
tools/slice.ps1         시트를 잘라 투명 PNG로 만드는 스크립트
serve.ps1               Node 없이 쓰는 로컬 미리보기 서버
```

## 작동 원리 (교사용)
1. 결승전 시작 순간, 학생들의 능력치로 '자연스러운 순위'를 계산합니다(약간의 운 포함).
2. 비밀 조건을 모두 지키면서 그 순위와 **가장 비슷한** 배치를 찾습니다.
3. 정해진 순위대로 결승선을 통과하도록 레이스의 허들·바나나·진흙·부스터, 배틀의 스킬 명중 시점을 배치해 연출합니다.
4. **k등 → k번 자리**. 교실 배치에서 자리 번호를 자동/랜덤/직접 매길 수 있습니다.

## 로컬 미리보기
```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```
→ http://localhost:8080 (교사) / http://localhost:8080/play.html (학생)

## 배포 (Vercel)
- 교사: https://action-seat.vercel.app
- 학생: https://action-seat.vercel.app/play.html (방 화면의 QR/코드로 접속)

GitHub `main`에 올리면 Vercel이 자동으로 배포합니다. 직접 배포하려면 (사용자 환경변수 `VERCEL_TOKEN` 필요):
```powershell
powershell -ExecutionPolicy Bypass -File tools\deploy-vercel.ps1
```
